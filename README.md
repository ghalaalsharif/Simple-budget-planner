## 📌 Project Overview
The Simple Budget Planner is a software solution designed to help university students and young employees manage their personal finances. It addresses the common struggle of tracking daily income, expenses, and monthly budgets without requiring complex financial knowledge.

## ✨ Key Features
* Income Management: Record different sources of income (salary, allowance, freelance work).
* Expense Tracking: Add, categorize, and track daily/monthly expenses.
* Balance Calculation: Automatically calculate and display the remaining balance.
* Budget Alerts: Send notifications when nearing the monthly budget limit.
* Transaction History: View all recorded earnings and expenses in a simple layout.
